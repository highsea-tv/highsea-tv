# @highsea/brand

The highsea logo, app icons, fonts and default sounds. Usage rules, the icon spec and the don'ts are in [`docs/brand/logo.md`](../../docs/brand/logo.md).

## Outputs

| Import | Contents |
| --- | --- |
| `@highsea/brand` | SVG builders (`markSvg`, `wordmarkSvg`, `lockupSvg`, `iconSvg`), the icon list, font names and sound file names |
| `@highsea/brand/logo/*` | `mark`, `mark-small`, `wordmark` and `lockup` SVGs, each with `-mono` and `-ink` variants |
| `@highsea/brand/icons/*` | App icons for iOS, Android, macOS, desktop, web, tvOS, Android TV, webOS and Tizen, plus the link preview and splash images. Apple platforms get their source formats: an Icon Composer document (`apple/AppIcon.icon`) and the tvOS brand assets with layered image stacks. |
| `@highsea/brand/attribution/*` | Other organizations' logos their terms ask highsea to show: `tmdb.svg`, TMDB's "alt short" logo, unmodified, from [TMDB's logos and attribution page](https://www.themoviedb.org/about/logos-attribution). [TMDB's terms](https://www.themoviedb.org/api-terms-of-use) § 3 require it in an About or credits section, less prominent than highsea's own marks, with the notice `TMDB_ATTRIBUTION` in `@highsea/api-contract`. Not generated, not highsea's brand, and not to be recoloured. |
| `@highsea/brand/fonts.css` | `@font-face` for Geist and Geist Mono (variable `woff2`) |
| `@highsea/brand/fonts/*` | The font files and their license (`OFL.txt`) |
| `@highsea/brand/sounds/*` | The default sound pack as 48 kHz, 16-bit mono WAV, one file per event |

Every output is generated by `bun run build` and committed. `bun run check` (and the test suite) fails when a text output is stale or a file is missing. PNGs are only checked for presence, because their bytes depend on the zlib build.

## Using it

**Web:**

```css
@import "@highsea/brand/fonts.css";
```

```ts
import { markSvg } from '@highsea/brand'

markSvg({ title: 'highsea' }) // the Bone mark; `paint: 'mono'` follows currentColor
markSvg({ small: true }) // below 24px
```

**React Native:** register the static fonts and play the rendered sounds.

```ts
import { NATIVE_FONTS, nativeFontFamily, SOUND_FILES } from '@highsea/brand'

nativeFontFamily('sans', 'semibold') // 'Geist-SemiBold'
SOUND_FILES.select // 'felt-select.wav'
```

## Sources

- **Mark:** the geometry in `src/mark.ts` is the signed-off reference board's.
- **Wordmark:** outlined from Geist by `scripts/outline.ts` into `src/wordmark-data.ts`.
- **Icons:** `src/icons.ts` describes every image, and `src/apple.ts` the Apple documents. `scripts/build.ts` rasterizes them with resvg and writes the PNG, ICO and ICNS files itself.
- **Sounds:** rendered from the recipes in `@highsea/tokens`, which remain the source ([`design/assets/sounds`](../../design/assets/sounds/README.md)).
