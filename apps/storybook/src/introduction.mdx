# highsea design system

The living style guide for highsea tv: the tokens, themes, components, motion and sound that every highsea app is built from. Everything here renders from the real packages, so what you see is what ships.

## Where things live

| Package | What it holds |
| --- | --- |
| `@highsea-tv/tokens` | Colors and themes, type, spacing, elevation, motion and sound values |
| `@highsea-tv/brand` | The logo, app icons, fonts and rendered sounds |
| `@highsea-tv/ui-web` | The React components for web, desktop and TV web builds |

The rules for using them are in `docs/design-language/`.

## Using this workbench

- **Theme** (toolbar): Abyss Neutral, OLED black or High contrast. Every story follows it.
- **Platform** (toolbar): TV switches to the 10-foot focus look: a ring in `text` and larger focus scales.
- **Sound** (toolbar): turns UI sound on for every story. The Sound board plays regardless.
- **Accessibility** (panel): axe runs on every story. Violations fail the story tests.

## Sections

- **Foundations:** color and the contrast audit, typography, layout and elevation, motion, sound, icons, the theme editor and the brand.
- **Components:** actions, forms, overlays, data display and feedback.
- **Media:** posters, the backdrop hero, carousel rows and ratings.
- **Shell:** the admin sidebar, command palette, widgets and the admin frame.
- **TV:** the home screen on the real spatial focus engine.

Sample titles are Blender Studio's open movies. Artwork is generated placeholder art.
