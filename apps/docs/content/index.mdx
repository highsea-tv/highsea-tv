highsea is one self-hosted server that finds, downloads and organises your films, with their subtitles. It takes the place of Radarr, Prowlarr, qBittorrent and Bazarr, and runs as a single Docker container.

These guides are for the person who runs the server. They were written against highsea 0.1.0.

## Install

[Installation](/install/) compares the ways to run highsea, and [Prerequisites](/install/prerequisites/) lists what it needs: a 64-bit machine with Docker, room for your films, a few ports and a free TMDB account. Then pick the guide for where highsea will run. Each one ends at the setup screen, which takes about five minutes.
