Written for highsea 0.1.0.

**Activity** is where you follow what highsea is downloading for the library, see what happened, and manage the releases it won't grab again. It has three tabs, **Queue**, **History** and **Blocklist**, and a **Manual import** button for files highsea didn't download or couldn't import on its own.

Owners and Admins use it. Users never open the admin.

Activity is about the library's downloads. The [Downloads](/downloads/) page shows the torrents themselves, including ones you add by hand, with their peers, trackers and files.

## The queue

**Queue** lists every film that's downloading or importing, live. A film moves to **History** once it's imported. The tab shows how many are in the queue.

Each row shows the film and the release's name, the quality, the size, the progress, the download speed (**↓**), the time left (**ETA**) while it downloads, and the status:

- **Queued**, **Checking** and **Downloading**: on its way.
- **Paused**: stopped by someone; **Resume** starts it again.
- **Stalled**: no data and no seeds for 2 hours.
- **Importing**: finished, and being brought into the library.
- **Import blocked**: finished, but highsea couldn't import it.
- **Seeding** and **Completed**: imported; the torrent is seeding or done.
- **Error**: something went wrong; the reason is under the status.

The filters above the list narrow it: **All**, **Downloading**, **Importing and seeding**, and **Needs attention** (stalled, import blocked and errors). Each shows its count.

### Pause, resume and remove

- **Pause** stops a download that's queued, downloading or stalled. **Resume** starts it again.
- **Remove from queue**, in the row's menu, stops the download and deletes its data. The film stays in the library, still monitored, so highsea goes on looking for it. You're asked to confirm first.

### Stalled downloads

A download with no data and no seeds for 2 hours shows **Stalled**, with the reason under it. At 3 hours, highsea blocklists the release and grabs another on its own.

To do it sooner, select **Replace**. highsea blocklists the stalled release and grabs the best remaining one in one step.

### Blocked imports

When a download finishes but can't be imported, its status is **Import blocked**, with the reason under it. Common reasons:

- the quality profile doesn't want what the file turned out to be, once highsea has read the file itself;
- there's no video file in the download, or only samples;
- an archive couldn't be unpacked, or held an executable file;
- the download's files are gone.

You can:

- **Find another**: blocklist the release and grab the best remaining one.
- **Import without the blocked file**, in the row's menu: import anyway.
- **Remove from queue**, in the row's menu.

Some releases are never left waiting. A torrent that lists an executable file is refused before anything downloads, then blocklisted and replaced. A release packed in a password-protected archive is blocklisted and replaced too, since it can never import. An executable found only once an archive is unpacked blocks the import, and says so.

### Blocklist and search again

**Blocklist and search again**, in any row's menu, blocklists the release and grabs another, at any point before it's imported. Use it when you know a release is wrong, for example the wrong film or a poor copy.

## What happens when a download finishes

When a film's download completes, highsea imports it on its own:

1. It finds the video file, skipping samples and extras, and extracts archives first if the release is packed.
2. It reads the file to check its quality and length, and checks it against the film's quality profile.
3. It names the file with your naming format and puts it in the film's folder.
4. If the film already had a file, the new one replaces it. With a recycle bin set, the old file goes there first.
5. It records the import in **History**, and looks for subtitles next.

How the file gets into the library depends on **Use hardlinks** in **Settings › Media management**:

- **Hardlinked**: when the downloads folder and the library are on the same disk, highsea makes a hardlink. The file appears in the library at once, takes no extra space, and the torrent keeps seeding from the original.
- **Copied**: when they're on different disks, or the disk doesn't support hardlinks, or hardlinks are turned off, highsea copies the file. It takes as much space again, and the torrent keeps seeding from the download.

The import's entry in **History** says which it was, and why when it had to copy. [Recommended setup](/recommended-setup/#folders-and-hardlinks) explains how to lay out folders so hardlinks work, and [Media management](/settings/media-management/) has the settings.

After the import, the torrent seeds until it reaches its seeding rule: a ratio or a time, whichever comes first. The default rule is in **Settings › Download client** (Owner only), and an indexer can have its own. When seeding stops, the library's copy stays. See [Downloads](/settings/downloads/).

## History

**History** records everything that happened to the library's films, newest first: **Grabbed**, **Imported**, **Import failed**, **Download failed**, **Deleted**, **Renamed**, **Blocklisted**, and the subtitle events (**Subtitles downloaded**, **Subtitles synced**, **Subtitles upgraded**, **Subtitles deleted** and **Subtitles not synced**).

Each entry shows the film, the release or what happened to it, the indexer it came from under **Source**, and when. **Show more** loads older entries.

A film's own history is also on its page, under **History**.

## The blocklist

**Blocklist** lists the releases highsea won't grab again: ones that failed, stalled, couldn't be imported, carried something unsafe, or that someone blocklisted. Each entry belongs to one film, so a blocklisted release can still be taken for another film. Each shows the film and release, the indexer and the reason.

**Unblock** removes a release from the blocklist, and highsea may grab it again.

## Import files by hand

**Manual import**, at the top of Activity, brings in files highsea didn't download, or a download it couldn't import on its own.

1. In **Folder**, choose a folder on the server. highsea starts in the downloads folder; **Folders here** and **Up** move around. You can browse the root folders and the downloads folder.
2. Select **Look inside**. highsea lists the video files in the folder and one level down.
3. Check each row:
   - **Movie**: the film each file matched. When a file **Didn’t match a movie**, choose one. Only films already in the library can be chosen; add the film first if it isn't.
   - **Version**: for a film with more than one version, which one the file is. Two files can't go to the same version.
   - **Becomes**: the name the file will get. After choosing a film by hand, select **Look inside** again to see it.
   - **Import**: clear the box to leave a file out.
4. Under **How to bring them in**, choose **Hardlink** (no extra space, and anything seeding keeps seeding) or **Move** (the files leave this folder). As with downloads, Hardlink copies when the folder is on another disk.
5. Select **Import**. Each file comes back imported, or with the reason it couldn't be.

The **Downloads** page can open Manual import on a finished torrent's folder too, with **Import into the library**.

### A library already on disk

Manual import's other mode, **Library import**, adds films already sorted into a root folder, where they are. It reads each folder inside the root folder as one film, by its name, such as `Title (Year)`, or with a TMDB or IMDb id in it. You choose a quality profile, and whether to **Rename to my format** or leave everything as it is. Matching needs a TMDB key in **Settings › General**, and the root folder must be added in **Settings › Media management** first.

If you're moving from Radarr, [Migrating from Radarr and qBittorrent](/migrate-from-radarr-and-qbittorrent/) brings your library and settings across instead.
