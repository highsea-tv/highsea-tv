Written for highsea 0.1.0.

highsea has its own torrent client built in, so there's no qBittorrent or Transmission to run beside it. **Settings › Download client** sets how it connects to other peers, when it stops seeding, and where torrents you add by hand go.

These settings are the Owner's alone: Admins don't see this area. Changes wait in a bar at the bottom of the page until you choose **Save** or **Discard**; categories save as soon as you change them.

The torrents themselves, with their speed limits, are on the [Downloads](/downloads/) page.

## VPN

The page opens with the state of the VPN in one line, and **VPN settings** to change it. Torrents follow the VPN chosen in **Settings › VPN**; see [VPN](/settings/vpn/).

## Seeding

![The Seeding section: Ratio 2 and Time, in hours 168, with the line that a torrent stops at whichever comes first and an indexer's own rule comes before this one](/images/admin/settings-downloads/seeding.png)

When a torrent stops seeding: at the ratio or the time, whichever comes first. When it stops, the film in your library stays.

| Setting | What it does | Default |
| --- | --- | --- |
| **Ratio** | Stops at this ratio of uploaded to size, from 0 to 100. Empty, no limit. | 2 |
| **Time, in hours** | Stops after seeding this long, up to a year. Empty, no limit. | 168 (7 days) |

This is the rule for every torrent whose indexer has none of its own. An indexer's own rule comes before this one, which matters for private trackers that ask you to seed for a minimum time. Set those on [Indexers](/indexers/).

With hardlinks, seeding takes no extra space, since the library's file and the torrent's are the same file. See [Media management](/settings/media-management/importing/#hardlinks-and-copies).

## When a download stalls

A download with no data and no seeds for 2 hours shows as stalled in Activity. After 3 hours, highsea blocklists that release for the film and grabs another release the profile accepts. When there isn't one, it tries again on the next search. A torrent that's paused, queued or checking, or that can't reach the network, isn't counted as stalled.

## When a download finishes

You don't need to set anything for completed downloads. When a film's torrent finishes, highsea:

1. extracts it, if it came as an archive;
2. names the file and its folder with your naming formats, when **Rename movies** is on;
3. puts it in the film's root folder, as a hardlink where it can, or a copy;
4. keeps seeding the original until the seeding rule is met.

If a download can't be imported, Activity shows it as needing attention, with the reason and the fix. [Media management](/settings/media-management/) has the naming, hardlink and archive settings, and [Activity](/activity/) has the queue and manual import.
