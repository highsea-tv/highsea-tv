Written for highsea 0.1.0. Themes are in **Settings › Appearance**, which the Owner and Admins can change.

![The Themes group: Abyss Neutral as the default, OLED black and High contrast built in, and a custom theme, Lighthouse, with Edit, Copy share code and delete, then New theme.](/images/admin/settings-appearance/themes.png)

The apps start in the **default theme**, and anyone can pick another on their own device. Choose the default from the cards: each shows the theme's colours and whether it's **Built in** or **Custom**.

There are three built-in themes:

| Theme | What it is |
| --- | --- |
| **Abyss Neutral** | highsea's own dark theme, and the default. |
| **OLED black** | True black backgrounds, for OLED screens. |
| **High contrast** | Stronger text and borders, and wider focus rings. |

## Make your own theme

![The theme editor for a new theme named Harbor night: Name, Based on, Accent, Quiet text and Contrast beside a preview with posters, a title and buttons.](/images/admin/settings-appearance/new-theme.png)

1. Under **Themes**, choose **New theme**.
2. Give it a **Name**, and choose the built-in theme it's **Based on**.
3. Pick an **Accent**. highsea makes the rest of the accent's shades from it, each readable against the background.
4. Optionally change **Quiet text**, the colour of captions and timestamps. **Reset** puts it back.
5. Check **Contrast**. Each pairing that's too faint is listed, with **Fix** where a lighter or darker shade solves it. A theme that fails can't be saved: someone would struggle to read it.
6. Choose **Add theme**.

The preview beside the editor shows posters, a title and buttons in the theme as you change it.

Each custom theme has **Edit**, **Copy share code** and delete. A share code is a short line of text that anyone can paste into **Load a share code** in their own editor to get the same theme. Deleting the default theme makes Abyss Neutral the default again.
