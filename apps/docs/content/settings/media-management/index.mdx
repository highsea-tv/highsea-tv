Written for highsea 0.1.0.

**Settings › Media management** decides where films live on disk, what they're called, and how a finished download becomes a file in your library. The Owner and Admins can change it.

![Settings › Media management, with the Naming card at the top and the Importing card below it](/images/admin/settings-media-management/page.png)

Changes to Naming and Importing wait in a bar at the bottom of the page until you choose **Save** or **Discard**. Root folders and tags save as soon as you change them.

## Keeping up with the disk

highsea notices changes you make to the library yourself:

- **The library scan** walks every root folder every 12 hours, and a film's folder again after each import. A file you add to a film's folder is read and recorded; a changed file is read again; a missing file is cleared from its film.
- **Watching** sees changes under a root folder as they happen, and asks for a scan of that film's folder a few seconds later.

Watching doesn't work reliably on network shares (SMB and NFS), and Linux limits how many folders can be watched. When a root folder can't be watched, System shows a note, and the 12-hourly scan still finds every change. You can run the scan yourself from System's tasks; see [System](/system/).

A root folder that can't be read at all, such as an unmounted disk, is skipped whole, so a missing disk is never taken as every file deleted.

## Tags

Tags tie films to the indexers, lists and connections that should serve them, and are managed in their own group at the foot of this page.

![The Tags card, with Anime used by no films and Kids used by one, each with Rename and Remove, and the New tag field](/images/admin/settings-media-management/tags.png)

- An indexer or connection with tags works only for films that share one of them. With no tags, it works for every film.
- A list's tags go on every film it adds.

Add a tag with **New tag**, then **Add tag**. Each tag shows how many films, indexers, lists and connections use it. **Rename** changes its label everywhere. **Remove** takes it off everything that has it, after you confirm; an indexer or connection left with no tags works for every film again.

![The dialog asking to confirm removing the Kids tag](/images/admin/settings-media-management/tag-remove.png)

Tags are given to films in each film's edit dialog. See [Movies](/movies/), [Indexers](/indexers/), [Lists](/settings/lists/) and [Notifications](/settings/notifications/).
