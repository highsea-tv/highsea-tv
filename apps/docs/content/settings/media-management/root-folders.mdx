Written for highsea 0.1.0.

A root folder is a folder your films are filed under, such as `/data/media/movies`. Each film gets a folder of its own inside one. Setup adds your first; most servers need only one.

Root folders are listed under **Importing** on **Settings › Media management**. Each shows its free space, how many films are filed under it, and **Can't be read now** when the disk isn't there. Changes to root folders save as soon as you make them.

![Two root folders, /data/films with no films and /data/movies with 7, each with its free space, its subtitle languages, Import what's already here and Remove, and the Add a root folder field below](/images/admin/settings-media-management/root-folders.png)

## Add a root folder

Type the folder's full path under **Add a root folder** and choose **Add folder**. The path is a folder on the server, as highsea sees it inside its container, not on the device you're browsing from. highsea checks that:

- the path is a full one, starting with `/`;
- the folder exists;
- highsea can write to it;
- it isn't a root folder already, or inside or around one.

Put it on the same disk as your downloads, so imports can use hardlinks. [Folders and hardlinks](/recommended-setup/#folders-and-hardlinks) explains why.

## Subtitle languages for films added here

Each root folder has a **Subtitle languages for movies added here** setting. Films added to that folder start with the languages you pick, from the language profiles on [Subtitles](/subtitles/). **None** means films added there get no subtitles until you choose some.

## Import what's already here

**Import what's already here** opens the library import in Activity for that folder. highsea reads each folder inside it as one film, by its name: `Title (Year)`, or with a `{tmdb-…}` or `{imdb-…}` ID in the name. It matches each on TMDB, so it needs a TMDB key (see [General](/settings/general/)).

You choose a quality profile, and whether to **Rename to my format**, which names folders and files with the [naming formats](/settings/media-management/naming/); otherwise nothing is moved or renamed. A folder with no match on TMDB says so: add `{tmdb-…}` with the film's TMDB ID to the folder's name and look again. [Activity](/activity/) has more on importing.

## Remove a root folder

**Remove** stops highsea using the folder for new films. Nothing on disk changes, and you can add it again later. A folder with films filed under it can't be removed: move them to another folder first.
