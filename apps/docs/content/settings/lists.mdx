Written for highsea 0.1.0.

**Settings › Import lists** adds films to the library on their own. Point highsea at a list, such as a TMDB chart, a friend's Trakt list or your Trakt watchlist, and every film on it that isn't in the library yet is added, with the folder and profiles you choose.

The Owner and Admins can both manage import lists.

## How lists work

- highsea checks each list that's on every 6 hours, and at once when you save it or press **Check now**.
- Each film on the list is matched on TMDB. A film the library already has, or one you've excluded, is skipped.
- New films are added as monitored, unless you turn **Monitored** off, so highsea looks for them as it does for any other film.
- A list only ever adds. Taking a film off the list, or removing the list, never removes anything from the library.

Each list's row shows when it was last checked and what happened: how many titles it found, how many were added, and how many were already there or excluded. Titles highsea couldn't match on TMDB are named, and a check that failed says why.

## Adding a list

Press **Add a list** and choose **Where the list lives**: **TMDB**, **Trakt** or **Generic list**.

### TMDB

Under **List**, choose:

- **A list**: a public list on themoviedb.org. Enter its number, or its address.
- **Popular**, **Top rated**, **Upcoming** or **Now playing**: TMDB's charts for the server's region. highsea takes the top 20.

### Trakt

Under **List**, choose:

- **A list**: a list on trakt.tv. Enter its address, such as `trakt.tv/users/sean/lists/blender`. Public lists work without signing in; your own private lists work once your Trakt account is connected.
- **Trending**, **Popular** or **Anticipated**: Trakt's charts. highsea takes the top 20.
- **Your watchlist**: the watchlist of the Trakt account connected on this page. Connect one first; see [Connecting Trakt](#connecting-trakt).

### Generic list

Enter the list's **Address**. It has to answer with a JSON list of films, each with its IMDb or TMDB id, in the format Radarr calls StevenLu Custom:

```json
[
  { "title": "Sintel", "imdb_id": "tt1727587" }
]
```

[MDBList](https://mdblist.com/) publishes lists this way, including lists drawn from IMDb and Letterboxd: use the list's JSON address there. highsea reads up to 5,000 entries from a generic list.

### What added films get

| Setting | What it does |
| --- | --- |
| **Name** | What the list is called in highsea. |
| **Root folder** | Where its films go. Add one in [Media management](/settings/media-management/) first. |
| **Quality profile** | The profile its films use. **HD 1080p** to start with. |
| **Subtitle languages** | The subtitle languages its films use, or **The root folder's default**. |
| **Tags** | Given to every film this list adds. |
| **Minimum availability** | **Announced**, **In cinemas** or **Released**: how far along a film must be before highsea looks for it. **Released** to start with. |
| **Monitored** | highsea looks for the films it adds. On to start with. |
| **Search when added** | Search every indexer for each new film at once, rather than waiting for new releases to turn up. Off to start with. |
| **Check this list** | Turn it off to keep the list without checking it. |

**Test** reads the list with these settings before you save, and says how many titles it found. **Save** adds the list and checks it at once.

## Managing lists

Each list's row has:

- a switch to turn it on or off;
- **Check now**, which checks it at once. New titles appear in **Movies**;
- **Edit**;
- **Remove**. highsea stops checking it, and the films it added stay in the library.

The check runs as **Import lists** in **System**'s tasks, too.

## Connecting Trakt

Your Trakt watchlist and private lists need highsea to be connected to your Trakt account. Public lists and charts don't.

1. Under **Trakt account**, press **Connect**.
2. highsea shows a code and an address on trakt.tv. Open the address on any device, sign in to Trakt, and enter the code.
3. Approve highsea on Trakt. The page shows **Connected as** your account once you have.

The code works for a limited time, which the page shows. If it runs out first, press **Connect** again for a new one.

One Trakt account is connected per server. **Disconnect** makes highsea forget it; lists that need it stop being checked until you connect again.

If the page says this build of highsea has no Trakt application, Trakt lists aren't available in it. highsea's published images include one; a build of your own may not.

## Exclusions

When you remove a film from the library, you can tick **Don't add it again from lists** (or **Don't add them again from lists** when removing several). The film then goes into **Exclusions**, and no list adds it again.

**Exclusions** lists them with when each was excluded. **Remove** one to let lists add it again.
