Written for highsea 0.1.0.

**System** shows what the server is doing and how it's holding up. Owners and Admins can open it. It has seven tabs, each at its own address: **Status**, **Health**, **Tasks**, **Logs**, **Events**, **Backups** and **Updates**. **Backups** is for the Owner only; Admins don't see it.

## Status

The first tab, at `/system`:

- Across the top: the **version**, how long the server has been **up for**, how many **apps connected** there are, and the indexer **catalog** version.
- **Resources**: CPU across every core and memory, as bars, with a line giving highsea's own share of each. The tab refreshes every 10 seconds.
- **Addresses**: the address **On the LAN**, and the **Remote** address, or **Not set**. The link goes to [Network and remote access](/settings/network/).
- **Disks**: each disk highsea uses, with how much is free and what's using it: movies, downloads and everything else. If none show, add a root folder in [Media management](/settings/media-management/).
- **About**: the server's name and version, where its film data comes from (TMDB), and the **Indexer catalog**: its version and when it was last checked, with **Check now**. A new catalog is installed from [Indexers](/indexers/).

## Health

**Health** lists what needs your attention, each with its level (**Notice**, **Warning** or **Error**), where it comes from, since when, and a message. The tab's count is the number of warnings and errors. The checks run on their own, and the list updates as things change. When there's nothing, it says "Everything's healthy".

What each message means, and what to do, by source:

### Indexers

- **No indexers are enabled, so searches find nothing.** Add one in [Indexers](/indexers/).
- **… has been failing.** The indexer keeps erroring; the message gives its last error. Check it in Indexers, or turn it off.
- **… needs a setting its new definition asks for.** The catalog changed the indexer. Open it in Indexers and fill in the new setting.
- **…'s definition is gone from the catalog, so it can't search.** Remove it, or replace it with another indexer.

### Catalog

- **A failed catalog check**, with its reason. highsea keeps the catalog it has. Try **Check now** under **Status › About** later.
- **The local definition … doesn't validate, so it's skipped.** A definition file you added has a mistake. The log says what.

### Downloads

- **The torrent client can't accept connections: …** Usually the torrent port is taken or blocked. The Owner can check the **Listening port** in [Downloads](/settings/downloads/); check your firewall too.
- **… couldn't be imported: …** A finished download is blocked from import; the reason says why. Look at it in [Activity](/activity/).
- **The IP blocklist couldn't be updated: …** The blocklist's address may be wrong or unreachable. The Owner can check it in Downloads; highsea tries again each day.

### VPN

- **The VPN is down. Torrents are stopped until it's back.** Torrents resume on their own when the tunnel returns.
- **The VPN couldn't connect: …** Check your provider's settings in [VPN](/settings/vpn/).
- **VPN: … Open Settings › VPN to see why.** One of the VPN's checks failed; the VPN page shows which.
- **VPN: … didn't forward a port.** Downloads still work, but fewer peers can reach you.

### Network

- **The certificate in … can't be used: …** highsea's built-in HTTPS can't read the certificate or key in `/config/tls`. Replace them with a full chain and its key. See [Network](/settings/network/).
- **Discovery couldn't listen on UDP …** Something else is using the port apps use to find the server at home. Apps can still connect by address.
- **The external URL isn't HTTPS.** Passwords cross the internet unencrypted, and passkeys can't work. Set an `https://` address in Network.

### Subtitles

- **… refused the password** or **… refused the key.** Enter the provider's account again in [Subtitles](/subtitles/).
- **… has no downloads left today.** A notice. The provider is skipped until the time shown.
- **ffmpeg isn't installed, so subtitles can't be synced to the audio.** The official image includes FFmpeg. On your own install, install it, or set `HIGHSEA_FFMPEG` to its path.

### Import

- **unar isn't installed, so downloads that come as archives can't be imported.** The official image includes it. Otherwise install unar, or set `HIGHSEA_UNAR` to its path.

### Library

- **… isn't watched for changes.** A notice. highsea can't watch that folder for files you add or remove, so the library scan finds changes every 12 hours instead.

### Connections

- **Messages to … aren't arriving: …** or **A message to … was dropped after a day of trying: …** A notification connection is failing. Check it in [Notifications](/settings/notifications/).

### Backups

- **The restore from … didn't work, so the server went back to the database it had.** Nothing was lost; the message says why the restore failed. See [Backups](/settings/backups/).

### Database

- An error from the source **database** means highsea couldn't read its own database. Check that the disk holding the config folder is mounted, writable and not full, then restart the container.

## Tasks

**Tasks** lists the jobs highsea runs on a schedule, with each one's **State** (**Running**, **Queued**, **Idle** or **Failed**), how often it runs (**Every**), its **Last run** and **Next run**. A failed task shows its last error under its state. A task that's switched off reads **Off** under **Next run**.

**Run now** starts a task straight away. It's unavailable while that task is already queued or running.

The tasks include:

| Task | What it does |
| --- | --- |
| **RSS sync** | Reads new releases from your indexers |
| **Search for wanted movies** | Searches for missing films and upgrades |
| **Import lists** | Syncs your [lists](/settings/lists/) |
| **Check for stalled downloads** | Finds downloads that have stopped |
| **Scan the library** | Finds files added, changed or removed outside highsea |
| **Check movie availability** | Updates whether films have been released |
| **Search for wanted subtitles** | Searches for missing subtitles |
| **Upgrade subtitles** | Looks for better subtitle matches |
| **Refresh changed metadata**, **Refresh all metadata** | Keeps film details up to date |
| **Clear unused metadata** | Removes cached details nothing uses |
| **Check the indexer catalog**, **Check the VPN providers** | Looks for new indexer definitions and VPN providers |
| **Update the IP blocklist** | Fetches the latest blocklist |
| **Start and end announcements and featured sections** | Applies [Curation](/curation/)'s schedules |
| **Back up** | Makes the scheduled backup |
| **Clear old logs**, **Clear old notifications**, **Clear old indexer results** | Tidies up what's no longer needed |

## Logs

**Logs** shows the newest lines since the server started, each with its time, level, source and message.

- **Show** filters by level: **Everything**, **Info and up**, **Warnings and errors** or **Errors**.
- **Search the log** narrows the lines shown.
- **Download logs** saves every line from the last 14 days, the files highsea keeps in the config folder's `logs` folder, one a day.

How much the server writes down is the **Log level**, in [General](/settings/general/) under **Diagnostics**. Leave it at **Info (default)** unless you're chasing a problem.

### Crash reports

Below the log, **Crash reports** lists the reports highsea writes to the config folder when something fails, each with **Download report**, to attach to an issue. Nothing is sent anywhere. They're written only when **Write crash reports** is on, in **Settings › General** under **Diagnostics**.

## Events

**Events** shows what the server tells every connected app, live, newest first: each event's topic and the items it's about, with the time. Apps refresh what they show from these. It's useful when an app or a page didn't update and you want to see whether the server said anything. Events only appear while the tab is open.

## Backups

Owner only. **Backups** lists the server's backups with **Back up now**, **Download**, **Restore** and **Delete**. See [Backups](/settings/backups/) for how they work and how to restore one.

## Updates

**Updates** shows your version, the newest on your update channel (**Stable channel** or **Beta channel**), its release date and a link to its **Release notes**, and when highsea last checked. **Check now** checks again.

highsea doesn't update itself. In Docker, pull the new image and recreate the container; highsea backs up before it changes its database. See [Upgrading](/upgrade/). **Update settings** opens [General](/settings/general/), where the Owner chooses the update channel.
